DeepSeek Harness 绿色便携版
============================

这是什么
--------
把 DeepSeek 官方开源 Agent 运行底座（dsh）及其 Web UI 打包成自包含文件夹。
双击 launch.cmd 即可在本机启动 dsh web 服务，并自动打开浏览器访问。
无需安装 Node.js / npm / Electron 等任何运行环境——所有依赖都已内置。

系统要求
--------
- Windows 10 或更高版本（64 位）
- 能联网（dsh 需要访问 DeepSeek API，首次启动会联网拉取运行资源）

使用方法
--------
1. 把整个 ds-harness-portable 文件夹复制到目标电脑（U 盘 / 云盘均可）。
2. 双击文件夹里的 launch.cmd。
3. 等待服务就绪（首次会联网拉取资源，约几十秒），浏览器自动打开
   http://127.0.0.1:3080
4. 在页面中选择工作区 / 权限 / 模式，到 Settings -> Models 填入
   DeepSeek API Key，即可开始对话。

停止服务
--------
直接关闭浏览器标签不会停止后台服务。停止方法：
- 打开任务管理器，结束 node 进程；或
- 再次双击 launch.cmd（会检测到端口已占用并直接打开浏览器），
  然后手动结束 node 进程。

数据位置
--------
dsh 的运行数据（配置、会话等）保存在本文件夹内的 .dsh 目录，
不写入系统盘，复制走也不留痕迹。如需彻底清理，删除整个文件夹即可。

目录结构
--------
ds-harness-portable/
├─ launch.cmd              <- 双击这个
├─ bin\node.exe            <- 内置 Node 运行时
├─ node_modules\...        <- 内置 dsh 及全部依赖
└─ .dsh\                  <- 运行数据（首次启动后生成）

关于其它操作系统
----------------
本绿色版内置的是 Windows 版 Node。若需在 macOS / Linux 使用，
请将 bin\node.exe 替换为对应系统的 Node 二进制（v22.19+ 或 v24+），
并把 launch.cmd 的逻辑改写为 .sh 脚本（路径保持相对即可）。

常见问题
--------
Q: 双击没反应 / 黑窗口一闪而过？
A: 确认 bin\node.exe 与 node_modules 目录随文件夹一起复制完整，
   且目标电脑为 Windows 64 位。

Q: 浏览器没自动打开？
A: 手动访问 http://127.0.0.1:3080 即可。

Q: 提示端口被占用？
A: 说明已有 dsh 在运行，直接访问上面的地址；或先结束旧 node 进程。

Q: 换电脑后需要重新配置吗？
A: 不需要。配置存在本文件夹 .dsh 内，跟着文件夹走。
   仅 DeepSeek API Key 需在每台电脑的页面里重新填入（或自行配置环境变量）。
