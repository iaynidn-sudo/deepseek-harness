DeepSeek Harness 桌面客户端使用说明

这是什么

这是一个自包含的 PC 客户端：把 DeepSeek Harness（@deepseek-ai/dsh）的运行环境完整打包进原生窗口，H5 界面直接内嵌在应用里，不是浏览器访问，也无需联网安装任何插件。

如何启动

  • 双击桌面上的「DeepSeek Harness」启动器，或
  • 直接双击 ds-harness-app.exe（位于 dist\ds-harness-app-win32-x64\ 内）
  • 首次启动约 1~3 秒出现主窗口；右下角系统托盘有图标
关闭窗口不会退出程序，应用仍在后台运行。如需完全退出，右键托盘图标 → 退出。

托盘菜单

  • 打开主窗口：显示/聚焦主界面
  • 刷新页面：重新加载 dsh 界面
  • 重启 dsh 服务：当界面异常或卡住时使用
  • 设置：开关自动更新、配置 API Key
  • 帮助：打开本页面
  • 退出：完全关闭程序

配置 API Key（可选）

  • 打开设置 → 填写「DeepSeek API Key」→ 保存
  • 保存后会写入本文件夹的 .env 文件，需重启 dsh 服务（托盘 → 重启 dsh 服务）后生效
  • 也可手动编辑 .env：DEEPSEEK_API_KEY=你的key

自动更新说明

客户端内置的 dsh 是一个固定的离线版本。开启「启动时自动检查更新」后，每次启动会联网查询 npm 上的最新版本，有新版本时弹出提示。

由于本客户端为离线自包含包，更新需要重新下载打包好的新版本，无法在应用内自动热替换。检测到新版本时，点击提示可打开官方发布页获取最新安装包。

如不希望程序联网检查，可在设置中关闭「启动时自动检查更新」。

常见问题

  • 窗口没出来？ 检查右下角是否有托盘图标（蓝色 DS），右键「打开主窗口」。
  • 界面空白/报错？ 托盘 → 重启 dsh 服务；确认 ds-harness-app-win32-x64 文件夹保持完整，不要单独移动 exe。
  • 换电脑能用吗？ 能。整个文件夹拷贝到其它 Windows 电脑双击即用，无需安装。
  • 如何彻底卸载？ 直接删除整个文件夹即可，无残留注册表。
